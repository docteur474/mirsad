# مرصاد MIRSAD — نظام إشارات كريبتو متعدد الوكلاء (SPOT · إشارات فقط)

نظام asyncio يبث إشارات شراء مدروسة إلى تيليجرام. **لا ينفّذ أي أمر إطلاقاً**
(لا create_order في الكود) — المتداول ينفّذ يدوياً. SPOT فقط: لا رافعة،
لا مشتقات، لا شورت. ولا نعد بربح مؤكد في أي رسالة.

├── backtest.py                # اختبار تاريخي walk-forward سنة+

│   ├── base_agent.py          # العقد الأساسي + الفشل الآمن + نبض الصحة
│   ├── whale_agent.py         # حيتان/on-chain — قواعد حسابية
│   ├── sentiment_agent.py     # أخبار + LLM قابل للضبط + كاش 8 دقائق

## التشغيل خطوة بخطوة

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # عبّئ المفاتيح — لا أسرار في الكود
pytest -q                   # تأكد أن كل الاختبارات خضراء أولاً
python main.py              # إقلاع النظام — heartbeat خلال ساعة
```

## الاختبار التاريخي وقراءة مخرجاته

```bash
python backtest.py
```

- يجلب شموع 1h لمدة 370 يوماً ويحاكي قواعد النظام كاملة
(وقف ATR، تعادل +1R، جني جزئي 50%، مهلة 48h، رسوم 0.1% وانزلاق 5bps لكل جهة).
- لكل fold يقرأ: n عدد الصفقات، win نسبة الربح، avgR متوسط النتيجة،
  maxDD أقصى تراجع على منحنى R، sharpe، sumR.
- **walk-forward**: العتبة تُعاير على Train ثم تُقاس على Test لم تره — أي رقم
  تدريبي لا يُحتسب في التقييم. وسيط العتبات المقترحة ظاهر في النهاية لكنه
  **إرشادي فقط** وقد يكون overfitting — أكّده بـ forward-test قبل الاعتماد.

## قراءة تقارير تيليجرام

- **إشارة شراء**: أصوات الوكلاء الخمسة، الإجماع، الدخول/الوقف/الهدف،
  R:R الصافي بعد التكاليف، وتنبيه صريح لو قُلّص الحجم بسبب الرصيد.
- **+1R**: جُنيت 50% والوقف الآن تعادل — المخاطرة صفر اسمياً.
- **EXIT**: بِع الآن بسبب (هدف/وقف/تعادل/مهلة) مع النتيجة بوحدة R.
- **WARN**: وكيل انقلب VETO/AVOID أثناء صفقة مفتوحة — قرارك.
- **DAILY/WEEKLY**: أعداد، مجموع R، متوسط R، ودقة تصويت كل وكيل.
- **PING**: النظام حي + حالة كل وكيل، و DOWN عند تعطل أي وكيل/مصدر.
